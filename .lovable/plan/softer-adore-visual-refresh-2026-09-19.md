# Softer Adore visual refresh

## Goal
Restyle the existing Adore site to match the uploaded reference: charcoal rather than near-black, gently rounded surfaces, subtle double-tone borders, soft inset depth, and quieter contrast.

## Changes
- Replace the current severe black palette and sharp grid treatment with layered charcoal surfaces and smooth 16–18px corners.
- Remove the homepage screenshot carousel and all uploaded product images from the visible site.
- Remove the bot/logo icon from the navigation while keeping the Adore name as a simple text link.
- Refresh navigation, buttons, feature panels, footer, cookie notice, and page surfaces consistently across the site.
- Keep all existing pages, copy, links, search, filters, and interactive tools working.
- Verify the main page and shared navigation at desktop and mobile sizes.

## Technical notes
- Update shared semantic colors, radii, borders, and shadows in the global design tokens.
- Simplify the homepage structure after removing the screenshot area, preserving a balanced first screen.
- Keep the uploaded files stored but no longer referenced by the visible experience.
